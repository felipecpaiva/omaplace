# WP10 live checks (F5 `auto`, M4)

Ask Felipe right before each check. No synthetic input, no virtual monitor. Harmless apps only. The service wiring must
be in before steps 5 and 6.

1. [ ] Set `app_memory = "auto"` in `~/.config/omaplace/config.toml` and reload (`hyprctl eval '_G.omaplace.reload_config()'`).
2. [ ] Open scene A on desktop 3 and scene B on desktop 4 (`omaplace open`, one app each is enough).
3. [ ] Move one app of A to desktop 4 by hand. About 2 s later `$XDG_RUNTIME_DIR/omaplace/moves.json` holds one event
   with the class, `from_scene`, `to_scene`, a rect and an order. No title anywhere in the file.
4. [ ] Move an app of A to a desktop that shows no scene: `moves.json` gets no new event.
5. [ ] With the service wired: the app is now in scene B in `scenes.toml` and gone from A.
6. [ ] Re-open scene B on a clean desktop: the moved app comes up at the remembered spot.
7. [ ] Close every window of desktop 4: no event, and the binding is dropped (open scene A again, move an app to
   desktop 4: no event).
8. [ ] Set `app_memory = "last_place"` and repeat step 3: no event.
